# Blog App Frontend

Frontend for the Full Stack Blog Application built using React and Vite.

This frontend provides:

- Authentication pages
- Dashboards
- Article management UI
- Comments system
- Profile settings
- Theme switching
- Responsive layouts

---

# Frontend Tech Stack

- React 19
- Vite
- React Router DOM
- Tailwind CSS
- Zustand
- Axios
- React Hook Form
- React Hot Toast

---

# Frontend Development Process

1. Created React app using Vite

2. Organized folder structure

3. Configured routing using React Router

4. Designed reusable components

5. Connected frontend with backend APIs using Axios

6. Added Zustand for state management

7. Added authentication handling

8. Added protected routes

9. Designed dashboards for:

- Users
- Authors
- Admins

10. Added toast notifications

11. Implemented responsive UI using Tailwind CSS

12. Added theme switching support

13. Configured deployment using Vercel
